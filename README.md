# Azure Data Factory Project

## Project Overview
End-to-end Azure Data Engineering project using Azure Data Factory (ADF).

## Technologies
- Azure Data Factory
- Storage Account (Data Lake)
- Azure SQL Database
- Azure Data Lake Storage Gen2
- GitHub

## Data Engineering Implementation
- Data ingestion from multiple sources
- Bronze, Silver, and Gold data layers
- Mapping Data Flows
- Data transformations and joins
- Aggregations and ranking

## Business Analytics
- Total revenue by airline
- Top 5 flights by revenue
- Top 5 busiest airports
- Top countries by flight bookings
- Passenger booking analysis
